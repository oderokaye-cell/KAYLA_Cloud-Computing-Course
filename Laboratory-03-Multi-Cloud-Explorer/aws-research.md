# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of services for computing, storage, databases, networking, security, analytics, and application development. AWS allows organizations to build and run applications without maintaining all of their own physical infrastructure.

## Global Infrastructure

AWS operates a global infrastructure made up of geographic Regions and Availability Zones. AWS currently lists 39 launched Regions and 123 Availability Zones, with infrastructure distributed across major geographic areas around the world. Each Region contains multiple isolated Availability Zones to support availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It provides centralized access to individual service consoles and features such as service search, notifications, CloudShell, account information, billing, and resource management.

## Four Core Services

1. **Amazon EC2** – Provides scalable virtual servers for running applications.
2. **Amazon S3** – Provides scalable object storage for files, data, backups, and other objects.
3. **Amazon RDS** – Provides managed relational databases.
4. **AWS IAM** – Manages identities, users, roles, and access permissions.

## Three Advantages

1. **Wide range of services** – AWS provides many services for different cloud computing requirements.
2. **Global infrastructure** – Organizations can deploy applications across multiple Regions and Availability Zones.
3. **Scalability** – AWS resources can be increased or decreased according to application demand.

## Typical Enterprise Use Cases

* Hosting enterprise websites and applications
* Data storage and backup
* Database management
* Disaster recovery
* E-commerce applications
* Data analytics
* Artificial Intelligence and Machine Learning
