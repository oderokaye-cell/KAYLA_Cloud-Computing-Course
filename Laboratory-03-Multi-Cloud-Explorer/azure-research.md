# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's global cloud platform for building and running applications and services. It supports both Windows and Linux workloads and provides infrastructure, managed services, databases, networking, security, AI, and other cloud capabilities.

## Global Infrastructure

Azure has a large global infrastructure consisting of regions and datacenters distributed around the world. Microsoft currently lists more than 80 Azure regions and more than 500 datacenters. Azure's geographic coverage helps organizations meet requirements for low latency, data residency, and compliance.

## Cloud Management Console

The **Azure Portal** is a web-based unified console for creating, managing, and monitoring Azure resources. Users can create virtual machines, databases, storage resources, and other services through a graphical interface. The portal also provides search, dashboards, Cloud Shell, notifications, settings, and resource management features.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual machines for Windows and Linux workloads.
2. **Azure Blob Storage** – Provides scalable object storage for unstructured data.
3. **Azure SQL Database** – Provides a managed relational database service.
4. **Microsoft Entra ID** – Provides identity and access management for cloud and on-premises environments.

## Three Advantages

1. **Microsoft integration** – Azure integrates strongly with Microsoft products and technologies.
2. **Global infrastructure** – Azure provides regions and datacenters around the world.
3. **Enterprise capabilities** – Azure provides security, compliance, monitoring, and management features for organizations.

## Typical Enterprise Use Cases

* Windows Server migration
* Microsoft 365 integration
* Enterprise application hosting
* Database management
* Backup and disaster recovery
* Artificial Intelligence and Machine Learning
* Hybrid cloud deployments
