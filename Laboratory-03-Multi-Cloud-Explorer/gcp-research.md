# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, data analytics, Artificial Intelligence, Machine Learning, networking, security, and application development.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Its regions are distributed across Asia, Australia, Europe, Africa, the Middle East, North America, and South America. Zones within regions are connected using high-bandwidth, low-latency networks, helping provide redundancy and improve application performance.

## Cloud Management Console

The **Google Cloud Console** is a web-based graphical interface used to manage Google Cloud projects and resources. Google Cloud also provides Cloud Shell, the Google Cloud CLI, client libraries, and infrastructure-as-code tools for managing resources.

## Four Core Services

1. **Google Compute Engine** – Provides virtual machines for running applications and workloads.
2. **Google Cloud Storage** – Provides secure and scalable object storage.
3. **Cloud SQL** – Provides managed relational databases such as MySQL, PostgreSQL, and SQL Server.
4. **Google Kubernetes Engine (GKE)** – Provides a managed environment for running containerized applications using Kubernetes.

## Three Advantages

1. **Strong AI and Machine Learning capabilities** – Google Cloud provides many tools for AI, ML, and data analytics.
2. **Kubernetes expertise** – GCP provides Google Kubernetes Engine for managed Kubernetes deployments.
3. **Data analytics** – Services such as BigQuery provide powerful tools for analyzing large datasets.

## Typical Enterprise Use Cases

* Artificial Intelligence and Machine Learning
* Big data analytics
* Kubernetes and containerized applications
* Website and application hosting
* Data warehousing
* E-commerce platforms
* Cloud-native application development
