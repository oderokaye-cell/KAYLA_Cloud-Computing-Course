# Mission Reflection

Completing Mission 3 helped me understand how the major cloud platforms, AWS, Microsoft Azure, and Google Cloud Platform (GCP), are used in real-world situations. Among the three platforms, AWS impressed me the most because it offers a very broad range of cloud services and can support different types of organizations. I also learned that Azure is a strong choice for organizations that already use Microsoft technologies, while GCP is especially useful for Artificial Intelligence, Machine Learning, data analytics, and Kubernetes.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, networking, identity management, databases, security, and other cloud services. They also allow organizations to scale resources according to their needs and provide global infrastructure for applications and businesses. Although their services have different names, many of them perform similar functions.

Business requirements strongly influence cloud platform selection. A company should consider its budget, existing technologies, application requirements, security needs, scalability, location of users, and type of workload. For example, Azure is suitable for a university already using Windows Server and Microsoft 365, while GCP can be a strong choice for an AI research company. AWS can be suitable for startups and global businesses because of its broad services and scalability.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I need to analyze the client's requirements first and then match those requirements with the appropriate cloud services.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added research documents, comparison tables, client recommendations, decision matrices, Linux investigation results, and screenshots as evidence. This made my repository more organized and professional and helped me practice documenting my technical work clearly.
