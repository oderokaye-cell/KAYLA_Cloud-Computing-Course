# Mission 3 Reflection

## Multi-Cloud Explorer Reflection

After completing this laboratory activity, the cloud platform that impressed me the most was Amazon Web Services (AWS). I found AWS impressive because it provides many different cloud services that can support various business and technical requirements. However, Microsoft Azure and Google Cloud Platform (GCP) also have important strengths that can make them suitable for specific organizations.

AWS, Azure, and GCP have several similarities. All three are major public cloud platforms that provide computing, storage, networking, identity, databases, and other cloud services. They also allow organizations to use cloud infrastructure without maintaining all physical infrastructure themselves. This makes it possible for businesses to select services based on their specific requirements.

Business requirements are important when selecting a cloud platform because different organizations have different needs, budgets, technologies, and goals. For example, a university already using Microsoft technologies may benefit from Azure, while an organization focused on artificial intelligence may consider GCP. A global company may prioritize scalability, availability, and worldwide infrastructure when choosing a provider.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The decision should be based on the client's actual problem, technical requirements, budget, and future growth. Comparing services also helped me understand why different cloud platforms can be appropriate for different situations.

My GitHub Cloud Computing Portfolio improved after completing this mission because I added organized documentation about three major cloud platforms. The research files, comparison tables, client recommendations, decision matrix, and screenshots make the portfolio more complete and demonstrate my understanding of multi-cloud concepts.
