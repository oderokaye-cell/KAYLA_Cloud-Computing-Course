# Cloud Concepts Reflection

I use several cloud services every day that make my schoolwork and personal activities more convenient. Three of the cloud applications I regularly use are **Google Drive**, **Canva**, and **Messenger**. Google Drive helps me store, organize, and access my documents from any device with an internet connection. Canva allows me to create presentations, posters, and other school projects online without installing software. Messenger enables me to communicate with my classmates, friends, and instructors instantly.

These services are examples of the **Software as a Service (SaaS)** model because they provide ready-to-use applications through the internet. As a user, I simply access the services without managing the servers or software behind them. They are also considered part of the **Public Cloud** deployment model because they are available to the general public over the internet and are maintained by their respective providers. This allows users like me to access them anytime and anywhere while benefiting from secure storage and automatic updates.

Learning about **Git** and **GitHub** has helped me understand the importance of version control in cloud computing projects. Version control is essential because it records every change made to files, making it easy to review, restore previous versions, and avoid losing important work. GitHub also makes collaboration easier by allowing multiple team members to work on the same project without overwriting each other's changes. Features such as commit history, branches, and pull requests help organize teamwork, monitor progress, and reduce errors when managing cloud-based resources.

Overall, this activity helped me realize that cloud computing is already a part of my daily life. Understanding cloud service models, deployment models, and version control has given me a better appreciation of how modern technology supports learning, collaboration, and productivity.
